# Demo video / GIF (15-20 seconds, no voice needed)

Tools (free): ScreenToGif, or Xbox Game Bar (Win+G) / OBS for video, ezgif.com to turn a clip into a GIF.
Settings: 1080p, record only the top-centre part of the screen (crop to ~1000x300 for the GIF so the file stays small, under ~8 MB).

Shot list
1. 0-3 s   Empty desktop. Pure black pill at the top. Caption: "Windows, but with a Dynamic Island."
2. 3-8 s   Start a song on YouTube/Spotify -> the pill expands with cover art, colours and progress. Click pause / next on the pill.
3. 8-12 s  A Telegram/WhatsApp message arrives -> banner pops out.
4. 12-16 s Start the timer. Drag a music file onto the pill.
5. 16-20 s End card: "HALO - free for Windows" + the link ecch1369.github.io/halo

Tips
- Use a nice wallpaper and a clean taskbar; first impressions are visual.
- Save the GIF as docs/demo.gif, then in README.md remove the <!-- --> around the demo line and push again (run publish-to-github.bat or commit from GitHub's web editor).
- Also take 2-3 PNG screenshots (idle, playing, notification) for Product Hunt.
